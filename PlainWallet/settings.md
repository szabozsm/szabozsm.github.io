# Settings

Open the menu (☰) and tap **Settings**. After changing anything, tap **Apply** to save and return to your card list.

## Card list view

| Option | What it does |
|-|-|
| One-column preview | Shows your cards in a single column. |
| Two-column preview | Shows your cards in two columns, so more fit on screen. |

## Cloud storage

Tick **one** provider to turn on cloud sync. Ticking one unticks the others.

| Provider | Fields |
|-|-|
| ExtendsClass | Api-key, Security-key, Bin id |
| JSONBin.io | X-Access-Key, Bin ID |
| JsonStorage.net | API key, User ID, Item ID |

Each provider also has:

- A **What's this?** link with in-app setup notes.
- A **Share** button that shows a QR code with the provider's details.
- A **Scan** button that reads such a QR code from another PlainWallet device.

For full instructions, see [Cloud Sync](cloud-sync.md).

## Internet access

| Option | What it does |
|-|-|
| **Access the internet only when connected to Wi-Fi** | ExtendsClass and JSONBin.io sync, and the background logo update, wait until Wi-Fi is connected. Does not apply to JsonStorage.net. |

## Saving your changes

Tap **Apply** to keep your changes. Settings you leave without applying are not saved.
